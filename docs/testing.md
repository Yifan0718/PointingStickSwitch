# 验证范围与复现

## 自动测试

在 Windows 上运行 `scripts/verify.ps1`，直接编译生产源码。每次运行的完整输出位于 `artifacts/tests/`。测试不会调用真实 PnP 禁用或厂商写入；实际系统交互限于只读枚举、专用测试管道及离屏绘图。

| 层次 | 内容 | 无法证明的事情 |
| --- | --- | --- |
| 目录 | 167 条官方 INF 模型行、别名、类别、用途、集合与错误根反例 | 所有相关物理机均能关闭指点杆 |
| 状态机 | 持久化、掉线、故障注入、设备替换、随机序列、并发 | 未知厂商内核驱动、固件行为 |
| Synaptics | 类型 4/5、共享触摸板、读写失败、身份变化、事务回滚与旧快照竞争 | 每种 SynCOM 版本均实现相同属性 |
| Windows IPC | 真实命名管道、ACL、服务器 PID、协议、超时与继续服务 | 所有多用户会话 / 域策略组合 |
| 枚举 | x64/x86 真实 SetupAPI 只读调用 | 在 32 位操作系统或 ARM64 上的安装实测 |
| 布局 | 6 档字体缩放 × 2 档宽度 × 2 种缩放模式 | 实际多显示器 DPI 切换和全部辅助功能设置 |

2.0.1 在本地 x64 与 x86 进程各通过 13,670 项断言。固定随机种子用于复现。CI 另在 GitHub Windows 托管虚拟机运行；CI 绿色不代表实体指点杆测试通过。

## 实机记录

`evidence/v2.0.0/` 是发布前已有的本地版本记录：Dynabook X30L-J / TOSB1008、64 位 SynCOM 实际读写、服务状态恢复、不影响其他 15 个输入设备、安装升级 / 卸载 / 重装。32 位厂商 COM 当时未注册，明确标为 SKIP。

`evidence/v2.0.1/` 保存此次发布复查的自动结果。2.0.1 尚未重新完成提升权限的完整安装 / 卸载循环；旧报告保留原版本，不挪作新版实测。安装包经过编译、元数据、嵌入文件哈希与启动检查，具体以该目录记录为准。

没有进行其他品牌实机、32 位 Windows 实机、真实休眠唤醒或外接蓝牙重连验证。共享 PS/2 等未知接口保持不可写。

## 手动硬件与安装验证

这些步骤会改变设备或已安装服务状态，不属于默认验证：

1. 记录当前设备与保存偏好，准备键盘和其他输入设备。
2. 安装 / 升级，核对服务路径、启动类型、桌面快捷方式、应用版本及四个二进制 / 配置文件哈希。
3. 普通用户往返启用 / 关闭，实际移动指点杆并核对触摸板、键盘、中键与滚轮；检查其他设备状态。
4. 检查重启服务、登录、唤醒和断开 / 重连的恢复行为。
5. 检查已关闭设备断开、厂商拒绝、卸载时程序仍在运行等失败路径。
6. 通过 `finally` 恢复测试前设备与偏好，记录 PASS / FAIL / SKIP 及软件版本。

不要为了覆盖率直接关闭通用 PS/2、USB 或键盘父节点。异常或无法证明独立接口时停止写入并保留诊断。
