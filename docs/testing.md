# 测试与复现

## 自动测试

在 Windows 上运行 `scripts/verify.ps1`。套件直接编译生产源码，使用模拟设备后端、真实命名管道、只读设备枚举和离屏绘图，输出位于 `artifacts/tests/`。

| 测试层 | 覆盖内容 | 执行方式 |
| --- | --- | --- |
| 设备目录 | 167 条官方 INF 模型行、别名、类别、用途、集合与实例根 | 硬件记录重放与正反例测试 |
| 状态机 | 持久化、掉线、设备替换、随机序列、并发和故障恢复 | 模拟后端与故障注入 |
| Synaptics | 类型 4/5、共享触摸板、读写、身份变化、事务回滚和恢复快照 | 生产策略模拟 |
| Windows IPC | ACL、服务 PID、协议、超时与后续请求 | 真实命名管道 |
| 枚举 | 设备属性与本机接口 | x64/x86 SetupAPI 只读调用 |
| 布局 | 6 档缩放 × 2 档宽度 × 2 种缩放模式 | WinForms 渲染与文字测量 |

x64 和 x86 每套包含 13,670 项断言，随机操作使用固定种子。GitHub Actions 在 Windows Server 2022 虚拟机完成同一测试套件，并执行安装、覆盖升级和卸载，核对服务配置、四个安装文件的哈希、应用版本和两个桌面快捷方式。

## 手动硬件与安装测试

1. 记录当前设备和保存偏好，准备键盘及其他输入设备。
2. 安装或升级，核对服务、桌面快捷方式、应用版本与文件哈希。
3. 以普通用户往返启用和关闭，检查指点杆、触摸板、键盘、中键及滚轮操作。
4. 检查服务重启、登录、唤醒及断开 / 重连后的状态恢复。
5. 检查设备断开、驱动拒绝以及卸载时程序仍在运行等场景。
6. 在 `finally` 中恢复初始设备状态和偏好，记录结果与软件版本。

`tests/HardwareChecks.cs` 是 X30L-J 的专项测试入口，运行条件为管理员权限、TOSB1008 已连接且初始状态为关闭。扩展设备测试按硬件 ID 和实际控制接口建立专用夹具。
